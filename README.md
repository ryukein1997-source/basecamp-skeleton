# Cryptbase

**All bones, no bloat.** A local-first, zero-dependency skeleton for small web
apps — offline storage, hash routing, a CSS-variable theme engine, and UI
primitives — proven by two complete apps built on the same foundation:

- **Crypt Pantry** (`apps/pantry/`) — a polished fridge & pantry tracker with
  expiry alerts and a low-stock shopping list.
- **The Daily Crypt** (`apps/broadsheet/`) — a printable one-page broadsheet
  generator.

Built with **Kiro** (spec-driven development) for **Kiroween 2026**,
Skeleton Crew category. The full spec, steering docs, hooks and custom agent
configs live in [`.kiro/`](.kiro/) — start with
[`.kiro/specs/cryptbase/requirements.md`](.kiro/specs/cryptbase/requirements.md).

Status: spec phase — implementation in progress. See [BUILDLOG.md](BUILDLOG.md).
